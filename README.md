# Borhan Rahimi — Portfolio

Personal portfolio for Borhan Rahimi, an Observability Platform Engineering
intern at Costco IT with experience in platform reliability and full-stack
software development.

## Highlights

- Current Costco IT and H-E-B Digital experience
- Full-stack and Android project portfolio
- Observability, platform, backend, frontend, and database skills
- Responsive design with accessible light and dark themes
- Downloadable one-page résumé

## Built with

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validate

```bash
npm run lint
npm run build
```

The editable résumé source is in
`resume/Borhan_Rahimi_RESUME.html`, and the downloadable PDF is generated at
`public/Borhan_Rahimi_RESUME.pdf`.
